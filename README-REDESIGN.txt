# Arya Art — Premium Boutique Website

This folder contains the refreshed static website for GitHub Pages.

## What's updated
- Luxury boutique styling in blush, ivory, warm brown and champagne gold.
- Responsive mobile navigation.
- Two-column product grid on mobile.
- Catalogue search and category filtering.
- Current price only on catalogue cards; offer details remain on individual product pages.
- WhatsApp order buttons on product cards and existing product pages.
- Native product share action with copy-link fallback.
- Responsive product galleries and forms.
- Existing HTML product pages and image/video assets retained.

## Publish on GitHub Pages
1. Keep a backup of the current repository before replacing files.
2. Extract this ZIP.
3. Upload the contents of this folder to the repository root (the `index.html`, `products.html`, `style.css`, `script.js`, and `images/` folder should be at the root).
4. Commit the changes to the branch configured for GitHub Pages.
5. Open the published website and test the homepage, catalogue, several product pages, WhatsApp ordering and share buttons.

## Notes
- The website remains a static site and does not require a paid hosting platform.
- Product information and WhatsApp contact details were retained from the supplied project.
- The source ZIP referenced `images/crochet-floral-rakhi.mp4`, but that video file was not included. Add the original video at that path if it should appear on the product page.
