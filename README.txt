ARYA ART — ONE-PAGE SHOP

This package consolidates the current product catalogue into one mobile-first page.
Included: index.html, style.css, script.js, and the existing images/ folder (including supplied videos/assets).

Features:
- Keeps Arya Art logo image and blush/ivory/rose/gold design direction.
- Product cards remain on one page; no separate product-detail pages are needed.
- Two-column product grid on mobile; 3 columns on medium screens and 4 on wide screens.
- Search matches product names, categories, image alt text and price; category filter works with search.
- WhatsApp order button uses the existing Arya Art WhatsApp number.
- Share button shares a direct single-page link with the product name in the URL; falls back to copying.
- Keeps the existing catalogue products and product images from the supplied project files.

GitHub Pages deployment:
1. Download and unzip this package.
2. Back up your existing repository before replacing files.
3. Upload index.html, style.css, script.js and the images folder to the repository root.
4. Old individual product HTML pages may remain in the repository, but the new index page does not link to them. They can be removed later after you confirm the new page works.
